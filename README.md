# Event Reminder System

## Overview

The Event Reminder System is a Django REST Framework-based application designed to manage events and reminders efficiently. Users can create, view, update, and delete events and track their completion status.

## Features

* Create and manage events
* View upcoming events
* Track pending and completed events
* Update and delete events
* Mark events as completed
* REST API integration

## Technologies Used

* Python
* Django
* Django REST Framework
* SQLite
